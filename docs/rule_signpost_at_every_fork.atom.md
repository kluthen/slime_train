# Level rule 6: a signpost stands at every fork

## INTENT
Require that every fork of the loop is marked with a signpost.

## THE RULE / LOGIC
A signpost stands at every fork of the loop and shows which way the loop goes; it is not interactive (see req_interactive_objects_general).

## TECHNICAL INTERFACE
Parented to req_level_design_rules (level rule 6 of 20).

## EXPECTATION
Every fork in a shipped level has a signpost present.
