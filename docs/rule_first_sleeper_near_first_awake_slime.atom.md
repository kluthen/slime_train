# Level rule 18: the first sleeper sits close to the first awake slime

## INTENT
Place the first sleeper close to the first awake slime, so the child can discover waking on her own.

## THE RULE / LOGIC
The first sleeper is close to the first awake slime, which is what makes the first-play discovery of calling and waking work without an adult explaining it (see user_story_newcomer_p1, goal 3).

## TECHNICAL INTERFACE
Parented to req_level_design_rules (level rule 18 of 20).

## EXPECTATION
A playtest with the primary persona shows her finding the call on her own, with no adult explaining it (definition of done item 32).
