# Test level

The scenes of the test level. The design (layout, coverage, fixtures) is in
`specs/levels/test/README.md`. It never ships in the release build.

- `level.tscn`: the level. For now a greybox of section 1 (Meadow), made
  with the components in `src/components/` and generated by
  `tools/greybox_test_level.gd`. A debug build of the game loads it.

See `docs/dev/README.md`, "Levels and components".
