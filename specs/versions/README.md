# Versions

Each version's scope, and later its master spec, lives in its own folder.
Features can move to a later version at any time; every move is logged in
`../decisions.md` (D52).

| Version | Theme | Status |
|---|---|---|
| [`v1/`](v1/README.md) | **The full MVP** (D135): bare mechanics validated, the gameplay loop there, can be tried; never in a store. The test level only, played end to end on the phones, with the platform, parent, save and performance work of the build plan (D134). The train, calls, fusion, the camera, sessions and bedtime. No sound. The only objects are the frontier-gate set and the loop-start split zone. | master spec consolidated; building |
| [`v2/`](v2/README.md) | Content generation and tooling, reusable mechanics (interactive objects), easy level design, music, the first real level(s) (D134) | themes only |
| [`v3/`](v3/README.md) | Proper graphics (D134); the rest of sound for now (O102) | themes only |
| [`v4/`](v4/README.md) | Parent options (turning the code off) | placeholder |
| [`timeline.md`](timeline.md) | Features with no version yet | live |
